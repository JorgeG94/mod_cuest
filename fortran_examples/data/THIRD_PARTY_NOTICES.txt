Provenance of this copy
-----------------------------------------------------------------------

The files in this directory were copied verbatim, without modification,
from NVIDIA's CUDALibrarySamples repository:

    CUDALibrarySamples/cuEST/data/
        geometry/h2o.xyz
        geometry/ch2i2.xyz
        basis_set/def2-svp.gbs
        basis_set/def2-svp-ecp.gbs
        basis_set/def2-universal-jkfit.gbs

They are bundled here so the Fortran examples can be built and run
without a checkout of CUDALibrarySamples.

CUDALibrarySamples is licensed under the Apache License, Version 2.0;
a copy is provided at ../../LICENSE-Apache-2.0 in this repository. The
basis set files originate from the Basis Set Exchange and are covered
by the BSD 3-Clause License reproduced in section 1 above; their
per-file '!' comment headers carry the upstream BSE attribution and
have been left intact.

The NumPy notice from the upstream file has been omitted: it applies to
the Python API examples, which this repository does not use.
